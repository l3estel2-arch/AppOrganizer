# แอป "จัดระเบียบแอป" (Android)

## แอปนี้ทำอะไร
1. **สแกนและสรุป** แอปทั้งหมดในเครื่องที่มีไอคอนบนหน้าจอ
2. **เสนอหมวดหมู่อัตโนมัติ** 14 หมวด: โซเชียลและแชท, การเงินและธนาคาร, ช้อปปิ้ง, อาหารและเดลิเวอรี่, เดินทางและแผนที่, วิดีโอและเพลง, ภาพถ่ายและกล้อง, งานและเอกสาร, ข่าวและการอ่าน, สุขภาพและออกกำลังกาย, การศึกษา, เกม, เครื่องมือและระบบ, อื่นๆ (รู้จักแอปไทย เช่น K PLUS, SCB, เป๋าตัง, LINE MAN, หมอพร้อม)
3. **หน้าตรวจสอบก่อนเปลี่ยน** — เห็นทุกแอปพร้อมหมวดที่เสนอ ย้ายหมวด เปลี่ยนชื่อโฟลเดอร์ หรือสร้างหมวดใหม่ได้ **ระบบจะไม่บันทึกอะไรจนกว่าจะกด "ยืนยัน"** และมีหน้าสรุปให้ยืนยันอีกครั้ง
4. **แสดงเป็นโฟลเดอร์** ตามชื่อหมวด แตะเพื่อเปิดแอป กดค้างที่แอปเพื่อย้ายหมวด/ดูข้อมูลแอป กดค้างที่โฟลเดอร์เพื่อเปลี่ยนชื่อ
5. **แอปที่ติดตั้งใหม่** จะไปอยู่โฟลเดอร์ "ยังไม่จัดหมวด" พร้อมแถบแจ้งเตือนให้ตรวจสอบและยืนยัน

## ข้อจำกัดของ Android ที่ควรรู้
Android **ไม่อนุญาต** ให้แอปใดๆ สร้างหรือย้ายโฟลเดอร์บนหน้าจอหลักของยี่ห้อโทรศัพท์ (Samsung One UI, Xiaomi, Pixel ฯลฯ) — หน้าจอเหล่านั้นเป็นของผู้ผลิต
แอปนี้จึงทำงานเป็น **หน้าจอหลักของตัวเอง** มี 2 วิธีใช้:
- **ใช้เป็นแอปธรรมดา** — เปิดจากไอคอน "จัดระเบียบแอป" หน้าจอเดิมของโทรศัพท์ไม่เปลี่ยน
- **ตั้งเป็นหน้าจอหลัก** — กดปุ่ม "ตั้งเป็นหน้าจอหลัก" ในแอป แล้วเลือก "จัดระเบียบแอป" กดปุ่ม Home เมื่อไหร่ก็จะเห็นโฟลเดอร์ที่จัดไว้ (เปลี่ยนกลับเป็นของเดิมได้ทุกเมื่อที่ ตั้งค่า > แอป > แอปเริ่มต้น > หน้าจอหลัก)

แอปนี้ **ไม่ลบ ไม่ถอนการติดตั้ง และไม่แก้ไขแอปอื่น** และไม่ใช้อินเทอร์เน็ต

## วิธีสร้างไฟล์ APK เพื่อติดตั้ง (เลือก 1 วิธี)

### วิธี A: ผ่าน GitHub (ไม่ต้องติดตั้งโปรแกรมในคอมพิวเตอร์)
1. สมัคร/เข้าสู่ระบบ github.com แล้วกด **New repository** ตั้งชื่ออะไรก็ได้ เช่น `AppOrganizer`
2. กด **uploading an existing file** แล้วลากไฟล์และโฟลเดอร์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวมโฟลเดอร์ `.github` ด้วย) กด **Commit changes**
   - ถ้าโฟลเดอร์ `.github` ไม่ขึ้น (บางระบบซ่อนโฟลเดอร์ที่ขึ้นต้นด้วยจุด) ให้กด **Add file > Create new file** ตั้งชื่อ `.github/workflows/build-apk.yml` แล้วคัดลอกเนื้อหาจากไฟล์นั้นมาวาง
3. ไปที่แท็บ **Actions** รอประมาณ 3–5 นาทีจนขึ้นเครื่องหมายถูกสีเขียว
4. กดเข้าไปในงานที่เสร็จแล้ว เลื่อนลงไปที่ **Artifacts** ดาวน์โหลด `AppOrganizer-apk` (เป็นไฟล์ zip ข้างในคือ `app-debug.apk`)

### วิธี B: ผ่าน Android Studio
1. ติดตั้ง Android Studio (ฟรี จาก developer.android.com/studio)
2. **File > Open** แล้วเลือกโฟลเดอร์ `AppOrganizer` นี้ รอให้โหลดเสร็จ (ครั้งแรกอาจนาน 5–10 นาที)
3. **Build > Build App Bundle(s) / APK(s) > Build APK(s)**
4. กด **locate** ไฟล์อยู่ที่ `app/build/outputs/apk/debug/app-debug.apk`
   - หรือต่อโทรศัพท์ด้วยสาย USB (เปิด USB debugging) แล้วกดปุ่ม ▶ Run เพื่อติดตั้งตรงเข้าเครื่อง

## ติดตั้งลงโทรศัพท์
1. ส่งไฟล์ `app-debug.apk` เข้าโทรศัพท์ (LINE ส่งให้ตัวเอง, Google Drive หรือสาย USB)
2. แตะไฟล์ ระบบจะถามให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" ให้กดอนุญาต แล้วกด **ติดตั้ง**
3. ถ้า Google Play Protect เตือน ให้กด **รายละเอียดเพิ่มเติม > ติดตั้งต่อไป** (เตือนเพราะแอปไม่ได้มาจาก Play Store)

## ข้อมูลทางเทคนิค
- ภาษา Java, Android framework ล้วน ไม่มีไลบรารีภายนอก
- รองรับ Android 8.0 (API 26) ขึ้นไป, target API 35, Android Gradle Plugin 8.11.1, Gradle 8.14.3
- แก้คำสำคัญการจัดหมวดได้ที่ `app/src/main/java/com/thai/apporganizer/Categorizer.java`
